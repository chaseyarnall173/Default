# Light, Waves & Radiation

- `Light_Waves_and_Radiation_Textbook.pdf`: the full book (11 chapters, worked examples, answer key, glossary).
- `Light_Waves_and_Radiation_QUICK_VERSION.pdf`: a 12-page skim version (key ideas, your questions, summaries).

Rebuild (from `source/`): `python3 tools/assemble.py && python3 tools/quick.py`
(needs Chromium, Node with `npm install` in `source/tools`, and `pip install playwright pypdf beautifulsoup4`).
Per-chapter source lists are in `source/sources/`.
